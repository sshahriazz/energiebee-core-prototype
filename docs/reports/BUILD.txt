Rebuild from the repository root:
  python3 -m venv /tmp/technext-pdf-venv
  /tmp/technext-pdf-venv/bin/pip install -r scripts/report-requirements.txt
  /tmp/technext-pdf-venv/bin/python scripts/build-reports.py
Requires Google Chrome in /Applications (adjust the executable path for other systems).

PDFs are the final deliverables. HTML files are intermediate print layouts.
PDF postprocessing adds running headers, footers, page totals and bookmarks.
Body pages are A4. Detailed diagram sheets use A3 and one A2 landscape sheet.
Reports 03 to 06 have no diagrams and are A4 throughout. They use the 'flow' layout:
sections follow on without forced page breaks, table columns are sized from their
content, and headings, lead-in lines and short tables or lists are kept together.
Print using each PDF page's size, or use fit-to-page when larger paper is unavailable.
Rendered diagrams replace the collapsible Mermaid source blocks in the PDFs;
the source blocks remain available in the original Markdown.
Original technical dates, caveats, measurements and source references are retained.
